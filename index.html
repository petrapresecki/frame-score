What this is. The frame is graded, downsampled and read, and every measurement is stretched against the range real photographs actually occupy — untouched, they all average out to mid-grey and every frame sounds identical. Chroma, not brightness, decides the palette, so a pastel sky is not mistaken for a saturated one. Each band takes the colour that makes it different from the rest of the frame, so a large background cannot collapse the progression onto one chord.

Activity is the axis that separates lively from hypnotic. Detail, brightness and the absence of haze decide how long each note rings, how finely the phrase is placed, whether it restates twice inside a band, and how high it sits. Density alone was never liveliness.

Nothing is static. Four voices hold the chord, each breathing on its own cycle — twenty-three seconds, twenty-seven, thirty-two, thirty-seven — so they never align the same way twice. Chords crossfade between two banks, so the harmony moves without any pitch sliding. There is no continuous noise anywhere: texture is crackle, eleven milliseconds at a time.
